Der Tresor

Backups

Eine Sicherung aller Daten – Konten, Chips, Münzen, Shop-Sachen, Freunde, Statistiken, Feedback. Jeden Tag wird automatisch eine gemacht; die letzten 7 bleiben. Lade ab und zu eine herunter und heb sie auf deinem Gerät auf – dann ist sie auch sicher, wenn die Datenbank selbst kaputtgeht.

Aus einer Datei wiederherstellen

Für den Notfall: eine heruntergeladene Backup-Datei (.json) zurückspielen. Geht nur, wenn niemand spielt – kündige vorher ein Update an. Vorher wird automatisch eine Sicherung vom jetzigen Stand gemacht.
