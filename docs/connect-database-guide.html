Connect Poker Night to a database

This makes accounts and the leaderboard permanent. It takes 3 steps and about 5 minutes.

These pictures are simplified sketches, not real screenshots, so the real pages look a bit different. The red boxes show what to click, and the button names match the real ones.
1

Copy the connection string in Neon

Open console.neon.tech, choose your project, and click Connect.

console.neon.tech › your project
Dashboard
Branches
Tables
Settings

Project dashboard

Connect① click

A window opens with the connection string. Click Copy.

Connect to your database
Connection string
postgresql://••••••••@ep-••••••.neon.tech/neondb?sslmode=require
Copy② click

It starts with postgresql://. It works like a password, so paste it only into Render (step 2), never into a chat.

2

Paste it into Render

Open dashboard.render.com, click your poker-night service, then Environment in the left menu.

dashboard.render.com › poker-night
Events
Logs
Environment③ click
Settings

Environment Variables

+ Add Environment Variable④ click
Key
DATABASE_URL⑤ type exactly this
Value
postgresql://••••••••…⑥ paste (Ctrl+V / ⌘V)
Save Changes⑦ click

Render may ask how to apply the change. Choose Save, rebuild, and deploy or Save and deploy.

3

Wait about 1 minute, then check

Render restarts the game, and the game sets up its tables in Neon by itself. Then open your game and click 🥇 Leaderboard.

Before, with no database:
⚠ Test mode: no database is connected, so accounts and scores are deleted whenever the server restarts.
→
After: the yellow warning is gone. ✅
Accounts and scores are now permanent.
Done! Tell Claude it's saved. Claude will check the live site, create a test account and confirm it survives a restart.
Not working? In Render, open Logs. A line saying Could not open the database means the connection string was pasted incompletely. Copy it again and replace the value.
